## Задание 3. Настройка правил оповещений

В разделе Alerts создано базовое правило отправки уведомлений для проекта `python`. Триггером служит регистрация нового инцидента, а действием - отправка почтового уведомления участникам команды.

Для проверки правила инициировано тестовое событие. На привязанный почтовый ящик поступило письмо с метаданными сбоя - именем проекта, уровнем критичности `error`, окружением `prod` и системными тегами.

## Задание повышенной сложности

Для проверки интеграции подготовлен сценарий на Python. Исходный код расположен в файле [sentry_test.py](sentry_test.py).

В скрипте настроена инициализация клиента через `sentry-sdk` с указанием окружения (`development`), версии релиза (`devops-homework@1.0.0`) и параметров трассировки. Дополнительно передаются метаданные - профиль пользователя и кастомный тег сервиса. Скрипт формирует три события - информационное сообщение через `capture_message`, перехваченную ошибку словаря `KeyError` с расширенным контекстом и сбой `ZeroDivisionError`.

После запуска скрипта все события успешно доставлены в облако. Раздел Issues отображает новые инциденты с переданными тегами и параметрами окружения.
